# HR Analytics: Employee Attrition Dashboard

## 📊 Project Overview
This is an interactive HR Analytics dashboard designed to analyze workforce metrics, track employee attrition trends, and gain data-driven insights using Python and Power BI.

## 🐍 Data Preprocessing & Analysis (Python & Pandas)
Before building the dashboard, data cleaning, manipulation, and Exploratory Data Analysis (EDA) were performed using **Python** and the **Pandas** library to ensure clean and structured data input for visualization.

## 🚀 Key Dashboard Features & Visuals
* **Employee Count Card:** Displays key workforce metrics and employee counts.
* **Monthly Income by Department:** A clustered column chart breaking down monthly income across departments such as IT, Sales, Finance, and HR.
* **Attrition Analysis:** A donut chart illustrating the employee attrition rate (Yes/No distribution).

## 🛠️ Tools & Technologies Used
* **Python & Pandas** for data cleaning, transformation, and analysis.
* **Power BI Desktop** for interactive data visualization and dashboard design.
* **Data Source:** HR dataset.

## 📂 How to View
1. Download the `.pbix` file from this repository.
2. Open it using **Power BI Desktop** to interact with the dashboard.
